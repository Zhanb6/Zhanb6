### Selected work

**TourCode** - [https://tourcode.kz/](https://tourcode.kz/)<br>
Mobile app for tourist codes in Kazakhstan. Shared React and TypeScript codebase, native integrations, push notifications and automated tests.<br>
`Ionic React` · `Capacitor` · `TypeScript` · `Cypress`

**Fura24** - [https://fura24.kz/](https://fura24.kz/)<br>
Freight marketplace with shipment requests, driver bids and delivery statuses. Django API and Flutter app.<br>
`Django REST Framework` · `PostgreSQL` · `Flutter` · `Docker`

**AstanaHub Logistics**<br>
Local network platform for transport requests, approvals and monthly planning. Includes tariff calculations and an Ollama assistant.<br>
`Node.js` · `PostgreSQL` · `Docker` · `Ollama`

**HorecaPass**<br>
Flutter recruitment app for hotels and restaurants, backed by a Django API.<br>
`Flutter` · `Django REST Framework` · `iOS` · `Android`

**FastNumber** - [https://draw.ziz.kz/](https://draw.ziz.kz/)<br>
Event draw system with QR registration, unique participant numbers, an admin panel and a live screen. Runs on a local network without external services.<br>
`FastAPI` · `PostgreSQL` · `Next.js` · `Docker`
